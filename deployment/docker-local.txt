================================================================
BACKEND ON DOCKER (LOCAL)
================================================================
Status: verified working (build ok, /health ok, real query ok).

Prereqs:
  - Docker Desktop running.
  - backend/.env has the keys (DEEPSEEK_API_KEY, PERPLEXITY_API_KEY).
  - DB present: backend/data/db/hm.duckdb (~1.1 GB).


1. Create the Dockerfile
   In backend/, make a text file named exactly "Dockerfile" (no extension).
   Write the build steps inside it (not in the terminal):
       FROM <base image>  ->  install deps  ->  COPY code  ->  CMD start
   (Already created here: backend/Dockerfile + backend/.dockerignore.)


2. Build the image
   cd backend
   docker build -t retail-copilot-api .
   (First time ~5-15 min; image ~1.75 GB; later builds are cached/fast.)


3. Run the container
   cd backend
   docker run --rm -p 8000:8000 \
     --env-file .env \
     -v "$PWD/data/db:/app/data/db" \
     retail-copilot-api
   (--env-file = keys at runtime; -v = mount the DB; neither is in the image.)


4. Test
   curl http://localhost:8000/health
   # -> {"status":"ok"}

   curl -N -X POST http://localhost:8000/api/chat \
     -H "Content-Type: application/json" \
     -d '{"messages":[{"role":"user","content":"How many customers are there?"}]}'
   # -> streams 1371980 + a complete event


5. Frontend (separate terminal, no docker)
   cd frontend && npm run dev
   # Vite dev server; its /api proxies to localhost:8000.


Handy:
  docker images retail-copilot-api     # image + size
  docker ps                            # running containers
  docker logs <name>                   # container logs
  docker rm -f <name>                  # force remove
