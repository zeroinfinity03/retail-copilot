  - backend/.env me keys hon (DEEPSEEK_API_KEY, PERPLEXITY_API_KEY).
  - DB present ho: backend/data/db/hm.duckdb  (~1.1 GB).

----------------------------------------------------------------
STEP 0 -- the Dockerfile (dockerize karne ka PEHLA step)
----------------------------------------------------------------
  Sabse pehla kaam: backend/ me ek TEXT file banao, naam exactly
  "Dockerfile" (no extension), aur uske ANDAR build steps likho:

      FROM <base image>   ->  install deps  ->  COPY code  ->  CMD start

  (Ye file ke andar likhte, terminal me nahi. Terminal me sirf build/run.)

  Yahan ye files ALREADY bani hui hain (naya banane ki zaroorat nahi):
    backend/Dockerfile      : multi-stage image recipe (no yml needed, single container).
    backend/.dockerignore   : data/db, raw_data, .venv, .env exclude (image patli rahe).

  Already hai, to seedha STEP 1 (build) pe jao.

----------------------------------------------------------------
STEP 1 -- build the image
----------------------------------------------------------------
  cd backend
  docker build -t retail-copilot-api .

  Note: pehli baar slow (~5-15 min) kyunki prophet / darts / statsforecast
  compile hote. Image ~1.75 GB. Baad ki builds cached (fast).

----------------------------------------------------------------
STEP 2 -- run the container
----------------------------------------------------------------
  cd backend
  docker run --rm -p 8000:8000 \
    --env-file .env \
    -v "$PWD/data/db:/app/data/db" \
    retail-copilot-api

  Explanation:
    --rm                 : stop hone pe container delete (clean)
    -p 8000:8000         : host:8000 -> container:8000
    --env-file .env      : keys runtime pe inject (image me NAHI)
    -v .../data/db:...   : DB host se mount (image me NAHI)

----------------------------------------------------------------
STEP 3 -- test
----------------------------------------------------------------
  # health
  curl http://localhost:8000/health
  # -> {"status":"ok"}

  # real query (SQL agent + LLM + DuckDB + SSE stream)
  curl -N -X POST http://localhost:8000/api/chat \
    -H "Content-Type: application/json" \
    -d '{"messages":[{"role":"user","content":"How many customers are there?"}]}'
  # -> streams "1371980" then a complete event

----------------------------------------------------------------
STEP 4 -- frontend (alag terminal, no docker)
----------------------------------------------------------------
  cd frontend
  npm run dev
  # Vite dev server; uska /api -> localhost:8000 proxy backend se connect karta.

----------------------------------------------------------------
